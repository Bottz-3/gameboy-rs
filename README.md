# gameboy-rs
An audioless Gameboy emulator in Rust rendered via Pixels crate with MBC1 ROM support.
Further MBC support will be added.

## How to Run
1. Run ```git clone``` on this repo.
2. Place your .rom in the root folder of gameboy-rs and rename it to "game.gb"
3. Then cd into the gameboy-rs directory and execute ```cargo run```
